GeckoRegen

A self-healing regulatory intelligence monitor built for the Bright Data Scrape-Verse Hackathon. It scrapes regulator websites via Bright Data Scraper Studio, detects when scrapers break, auto-heals them via the Self-Healing API, independently validates the repair, and builds persistent organizational memory that learns from every change.

How to Read the Health Grid

Each regulator appears as a card in the bento grid. The colored dot and status text tell you the scraper's health:

Healthy — all fields populated, scraper working
Degraded — some fields missing (partial failure)
Broken — critical fields failing, needs healing

When a scraper breaks, the card pulses red. When it heals, it pulses green. This happens in real time via SSE.

What Happens When a Scraper Breaks

  1. Detector compares current output to last-known-good snapshot via JSONL diff
  2. Healer generates a contextual prompt: "Field X returns null on REGULATOR. Expected pattern: regex. Last-known-good: example." This is sent to Bright Data's Self-Healing API
  3. BD regenerates the scraper code. GeckoRegen polls until the fix is ready
  4. Validator re-runs the healed scraper and checks: field population rate ≥ 90%, format consistency, record count stable
  5. If validation passes → heal accepted, health turns green. If it fails → rejected, retried with a sharper prompt (max 3 attempts)
  6. Memory records the entire event: what broke, what prompt fixed it, how long it took

Architecture

  • bd_client.py — Bright Data API client (6 endpoints: trigger, dataset, heal, poll, approve, list)
  • db.py — SQLite database (5 tables: regulators, health_scores, changes, healing_events, regulator_profiles)
  • detector.py — snapshot diffing, failure detection, severity classification
  • healer.py — contextual prompt generation, BD Self-Healing API, validation gate
  • memory.py — regulator behavior profiles, impact correlation, regulatory timeline
  • monitor.py — orchestrator wiring all modules, concurrent scraper runner
  • adapter.py — adaptive scan frequency, anomaly detection
  • server.py — Flask API (8 routes + SSE for live dashboard updates)
